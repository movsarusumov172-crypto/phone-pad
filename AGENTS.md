# AGENTS.md — PhonePad

## Что это

iOS-приложение (телефон как экранный геймпад) + PC-сервер на .NET, который делает
виртуальный XInput-контроллер через ViGEmBus и считает тактильные эффекты из
телеметрии FH6.

## Сборка и проверка

Локально на этой машине **нет .NET SDK и нет Swift** — собирать только через CI:

```bash
# всё целиком
gh workflow run build.yml --repo movsarusumov172-crypto/phone-pad
# или пуш в main
```

Локально доступны только Python-инструменты:

```bash
python3 tools/phone_sim.py --mode selftest        # кодеков протокола
python3 tools/layout_preview.py --layout racing   # превью раскладки без устройства
```

## Грабли, на которые уже наступали

* **`name:` в workflow YAML с двоеточием и пробелом («Артефакт: …») ломает YAML** —
  значение надо закавычивать. GitHub покажет «Invalid workflow file» без номера строки.
* **`macos-14` на этой площадке мёртв** («The configuration 'macos-14-arm64-us-default' is not
  supported») — использовать `macos-15`.
* **Исходная iOS-часть из архива не компилировалась вообще**: `connection = nil` внутри
  `if let connection` (затенение `let`), несуществующий `CHHapticEvent.ParameterID.hapticFrequency`
  (в CoreHaptics у события только интенсивность и резкость — частоту приходится кодировать
  числом коротких импульсов), смешение `Float`/`Double` в синтезе звуков, неверные лейблы
  инициализатора (`green:` вместо `g:`). Проверять сборку в CI, а не «на глаз».
* **Симулятор рисует приложение, которому нужен только ландшафт, повёрнутым на 90°** —
  снимок `simctl io screenshot` приходится разворачивать (`sips -r 90`), иначе он выглядит
  как «сломанная вёрстка», хотя приложение отрисовано правильно.
* **Не оборачивать весь интерфейс в `GeometryReader`**: он сажает содержимое в безопасную
  зону, и раскладка уезжает внутрь от выреза. Для проверки ориентации использовать
  фоновый `GeometryReader` + `PreferenceKey`.
* **Панели поверх пада** (HUD) перехватывают касания — вешать их в строку статуса
  или отключать им hit-testing.

## Правила интерфейса

Раскладки живут в `ios/Sources/PadLayout.swift` в нормализованных координатах.
Раскладка считается под **ландшафтный экран iPhone 16 Pro: 874×402 pt**;
сверху зарезервировано 58 pt под панель статуса. Любую новую раскладку сначала
проверять превью-рендером (`tools/layout_preview.py`) и снимком из CI-симулятора:
элементы не должны наезжать друг на друга, подписи — вписываться в свой элемент,
а над падом должна оставаться ровно одна полоса (статус-бар).
